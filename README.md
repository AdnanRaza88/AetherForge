# AetherForge

Autonomous hierarchical multi-agent coding system.

Spec-driven. Model-agnostic (cloud APIs + local open-source models). Permission-first. Local-first.

Main Agent (Software Engineering Lead) orchestrates specialist Sub-Agents for software engineering, data science, ML/DL, testing, DevOps, security, and documentation work — primarily against GitHub repositories.

## Status

Planning phase complete (v0.1). Implementation not started.

See [docs/planning/](docs/planning/) for full PRD, system design, technical spec, schemas, agent instructions, roadmap, security model, UX spec, and source repositories.

## Key Principles

- Spec is the source of truth
- Hierarchical agents (Main + specialists)
- Explicit permission for non-trivial actions
- Works with any LLM provider and local models
- Clean, human-written code style
- Liquid glass / glassmorphism UI (light theme, restrained)
